# Skill gotchas

One line per gotcha: the skill reference it belongs in, then the fact.

- references/setup.md: `fetch_emu.py gba-bios` 404s; retrobios moved the file to `bios/Nintendo/Game Boy Advance/GBA_bios.rom` (same SHA-1 300c20df...). Fixed in the marketplace clone's `scripts/fetch_emu.py` (2026-11-15); push upstream.
- SKILL.md Step 0.2: plugin enabled in `.claude/settings.json` but not installed in `installed_plugins.json` (skill absent from the Skill list, hook not loaded); the `hooks` block in project settings with `$HOME/.claude/plugins/marketplaces/...` took effect mid-session without a reload.
- references/setup.md: no pytest on this Windows machine; the template's pre-commit `CHECK` assumes pytest. Used stdlib unittest via `tools/check.py`.
- references/emulator-qa.md §Hooks: Mesen GBA `emu.getState()` exposes registers as `cpu.r0`..`cpu.r15` (plus banked `cpu.irqRegs0`...); worth listing next to `L.pc()` so per-game hooks don't have to dump the key list first.
- references/emulator-qa.md §Hooks: `probes/ppudump.lua` with `--route-str` and no `--frames` exits 2 (needs `DUMP_AT`/`DUMP_EVERY`); the error is clear, but the usage line could say so.
- references/pipeline.md §Recon: GBA text with no Shift-JIS and no relative-search hit (font-index code page, kana in JIS order but punctuation/Latin/digits interleaved) was found fastest by `romreads.lua`-style PC/min/max logging over ROM during a typing window, then hooking the renderer's char read; a generic `probes/gba_romreads.lua` would save the hand-written one (`tools/lua/romreads.lua` here).
- references/graphics.md §Survey: GBA title/logo BGs here are 8bpp (BGxCNT bit 7); `vramfind.py --fmt gba4` gives plausible but wrong matches on 8bpp layers. Check BGxCNT in the `.io.bin` dump before choosing `--fmt`.
- references/emulator-qa.md §emu.py: without `--sav`, Mesen (portable) keeps the game's battery save in `tools/mesen/Saves/`; one `--mash` run that hit a SAVE prompt wrote a save, and every later cold boot defaulted to CONTINUE instead of NEW GAME. Debug-tool runs should always pass `--sav` (a blank 512-byte 0xFF file for GBA EEPROM here).
- references/emulator-qa.md §Hooks: two `--script` probes that read the same global (`watch.lua` and a second probe both on `WATCH_LO`) silently share the last `--var`; give per-game probes their own variable names.
- references/emulator-qa.md §emu.py: a `--mash` run with no route mashes from frame 0, so it can't be combined with a Lua warp that must reach the title untouched; set the `MASH` global from the warp script after arrival instead.
- references/pipeline.md §Marker build and engine spike: a decompressed font can overlap a later RAM buffer: here glyphs 0x1A0+ lie on the script buffer at EWRAM 0x0201E000, so the existing Western punctuation cells drew as noise in dialogue (fine in the staff roll). Check every glyph the English table uses against a RAM dump taken while a script is open, not just after boot.
- references/pipeline.md §Marker build and engine spike: an engine with a built-in VWF still constrains advances: here only multiples of 4 place correctly (odd ones dropped glyphs, 6 px drew the next glyph 6 px left), and two Japanese punctuation codes (、 」) are special-cased. A torture line with every punctuation mark between capitals (`H,H.H:H"H'H(H)…`) plus a pixel dump of the shot found both in two runs; reading the shot at 3x alone misled me twice.
- references/emulator-qa.md §Debug tool: field messages in this game close by themselves a few seconds after typing ends, so a long `HOLD` shot of a stress line lands on the field and looks like a crash; check the mode in the SHOT log line before bisecting.
- references/pipeline.md §Width gate: on this GBA engine an over-long line doesn't clip or wrap: the text tiles spill into the BG tile area and paint the whole screen with the glyph. One ruler build per candidate width (digits, 8 px each) found the limits in two rounds.
- references/emulator-qa.md §Debug tool: GBA game here: a script-id byte is overwritten by the story machine in the cutscene mode's first sub-state; swapping the id on entry to the next sub-state (exec hook) is what made "play any cutscene" work. Worth a line: hook after the picker, not before.
- references/translation.md §Batch design: a hard-coded "encodable" charset in batches.py passed `+`, which the font lacks; the first all-English build then failed. Build the set from the project table (`tbl/en.tbl`), and test every shipped `en` against it.
- references/translation.md §Second language (wrap by tool): a wrapper that slices an over-long sentence every N lines leaves one-word stub pages ("...said a thing about" | "it."); reviewers reading unwrapped text can't see it. Split the sentence into even pages at a clause break, and lint pages that continue a sentence with under ~8 characters.
- references/emulator-qa.md §Hooks: probes/watch.lua logs one line per distinct PC, so when the BIOS LZ77UnCompVram loop (pc 0x119C-0x1208) unpacks two blocks in one frame, only the first source shows. Logging ROM pages read in the frame (`tools/lua/rompages.lua` here) found the second block (the tilemap of a "graphics" message box).
- references/emulator-qa.md §Text coverage: on GBA, a "message viewer" that writes one u32 into cartridge ROM from Lua (`emu.write(off, b, emu.memType.gbaPrgRom)`) to repoint a script slot at any string, then warps to that script, reaches every string in ~5 s per cold boot; the game itself reads it, so textcover.lua counts it honestly.
- references/emulator-qa.md: warp/emu --keep --sheet (half size, --changed on the whole screen) drops most typed-text pages of a cutscene; pick the last shot before the text ink changes instead (tools/story_pages.py).
- references/emulator-qa.md §Visual QA: a message viewer's fixed-hold proof shot (HOLD frames after the first glyph) mostly shows a page still typing, fine for coverage but unjudgeable; and the carrier script may not wait at {page} (Ghost Trap: box clears ~6 frames after the FD handler). Hook the page-code handler from the interpreter's jump table, shoot a few frames later, and chain many strings per boot in a QA-only ROM copy (tools/pageview.py): every page fully typed, ~48 strings per cold boot.
emulator-qa.md: pageview-style chains through a message-viewer scene stop at a blank '{clr} {clr}' page in some strings (the real cutscene goes on past it); shoot the tail in the real cutscene with a page-handler probe (tools/lua/pageshot.lua) instead
